\begin{textbox}{degrade\_response}
# System
You edit responses for a controlled evaluation of grading rubrics. Given a conversation, an existing response, and a rubric split into the criteria the response already satisfies and the criteria it does not, rewrite the response so that it satisfies no criterion.

Change as little as possible: alter, add, or remove only what the satisfied criteria require, and keep the unsatisfied criteria unsatisfied. Preserve everything else — content, structure, wording, tone.

The rewritten response is a negative control for a rubric evaluation. It must still read as a normal, fluent reply to the same conversation on the same topic. Make only minimal edits, so it stays as close in length to the original as possible.

Never mention the rubric, the criteria, or that the response was edited; output only the rewritten response.

# Message
Rewrite the response so it satisfies no criterion below.

# Criteria it satisfies — change the response so it does not
{satisfied}

# Criteria it does NOT satisfy — keep them unsatisfied
{unsatisfied}

Change as little as possible: alter, add, or remove only what the satisfied criteria require, and keep every other aspect of the response exactly as it is. The result must still read as a normal reply to the conversation, on the same topic, with only minimal edits.

# Conversation
{conversation}

# Response
{response}
